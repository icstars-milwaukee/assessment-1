# Assessment 1 — Hello World

Clone this repository, then create a branch named `firstname-lastname` (all lowercase).
Add your own unique section to `HelloWorld.md`, and push your branch to the remote.

This is a Git challenge: the goal is to figure out the correct commands on your own. The `main` branch will push back, but your branch will let you through. Please do not edit anyone else's section.

Show your personality, keep it clean, and make your hello world truly your own.
